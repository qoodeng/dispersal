# Dated environments in the population engine

The population map now runs six geographic windows at five dated climate slices (120,100,80,60,40ka BP) and a modern baseline. Region/date changes replace actual terrain coverage, climate and integrated density references supplied to Rust. These are exploratory modern-analogue transfers, not ancient occupation or arrival reconstructions. Each100-year run freezes the environment at its selected date.

Source identities, hashes, variables, methods and all36 artifact hashes are in `public/spatial/dated/manifest.json`. Reproduction: `python scripts/prepare-dated-worlds.py /path/to/Beyer2020_annual.nc`, then compile/copy the WASM engine and run `node scripts/check-dated-worlds.mjs`. Climate archive acquisition is documented in scripts/acquire-ecology.py and research/ecology/acquisition.json. The generator preserves the existing fit coefficients, native climate support,500 coefficient bootstraps, geographic CV error and physical-area integration.

Marine coverage uses four-connected flood fill of native ETOPO cells below the selected global median sea level, seeded in deep Mediterranean (34N25E), Red Sea (20N38E), and Arabian Sea (15N58E) cells. Source elevations at these seeds are checked below each selected level. This avoids treating an isolated inland depression as marine water. It does not reconstruct freshwater, tectonics, glacial-isostatic adjustment, or ancient relief. Modern EGM2008 and global relative sea-level references are an explicit approximation. The modern scenario sets0m; ancient dates use the published Spratt/Lisiecki median, not the PC1 or an invented curve.

Rust now accepts explicit Open/Blocked/Unknown coverage independently of elevation. Negative-elevation land can remain traversable. Whole-segment raster checks still govern graph edges. Synthetic origins are the six supported reachable sites nearest(-28,-28)km relative to the chosen center; they are not archaeological camps. Two Nile date windows have zero supported density sites, which means the fitted model cannot run there, not that ancient people could not occupy the Nile. The interface explains this and keeps the map available.

Rainfall/temperature layers, site destination values and source links show the inputs used. The exported run includes the complete selected world, all frames and exact trips. Environment dates are separated from elapsed simulation time. The TypeSafe.AI-inspired visual system is retained.

This does not close the master scientific plan. Fitted food supply, freshwater, food-dependent demography, validated movement/fission/coastal behavior, evolving environments, regional convergence, archaeology likelihood, inference and independent historical validation are not supplied by these window experiments.
